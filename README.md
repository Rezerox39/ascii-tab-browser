# AsciiTab Browser

A lightweight Android browser inspired by Via Browser, with an ASCII-animal themed new tab page.

## Features (planned)
- Fast WebView-based browsing with minimal chrome
- Custom ASCII new tab (14 animals, search, clock, tweaks)
- Google search / URL bar
- Ad & tracker blocking (request-level)
- Dark mode
- Tabs, bookmarks, history (coming)
- Incognito mode (coming)

## Build
CI builds APK via GitHub Actions. Local build requires Android SDK 34 + JDK 17:
```
./gradlew assembleDebug
```
